Like any first class, we start with the basics.

What is calculus good for? Calculus is used throughout the world for many things. Most people know that calculus is used in physics, chemistry and economics, but it's also used in construction, medicine, geology. If you plan on working in any of the sciences, then you'll likely be using calculus.
